Privacy Policy

Last updated: November 14, 2026

About Raspberry Backup

Raspberry Backup is a personal backup solution using rclone to store encrypted Raspberry Pi backup files in Google Drive.

Google Drive access

The application requests permission to access files created by the application in Google Drive. This access is used to upload, list, retrieve and manage personal backup files.

Data storage and security

Backup files are encrypted locally before being uploaded to Google Drive. OAuth credentials are stored locally and are not published on this website.

Data sharing

The application is for personal use. Backup contents are not intentionally shared with third parties. Google Drive processes uploaded data according to Google's privacy terms.

Revoking access

Google Drive authorization can be revoked at any time through the Google Account security settings.
